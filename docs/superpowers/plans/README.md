## 지금은 따르지 않아도 되는 것

- 계획 3b, 4, 5, 7 의 **"병렬 작업 규칙"**(같이 쓰는 파일은 맨 끝에 추가만, 기존 줄은 고치지 않기 등)은 여러 세션이 동시에 구현할 때 충돌을 줄이려던 당시의 약속이다. 구현이 끝난 지금은 따르지 않는다. 그 규칙 때문에 생긴 흔적(파일 끝의 import, 계획 번호 주석, 숫자 붙은 이름, 계획별로 나뉜 채널 타입)은 정리했다.
- 계획 안의 파일 경로, 함수 이름, 코드 조각은 쓸 당시의 것이다. 정리하면서 이름이 바뀐 것이 있으니(예: 계획별 채널 타입은 `src/shared/api.ts` 의 `InvokeChannels` 하나로 합쳐졌다) 코드를 기준으로 본다.
